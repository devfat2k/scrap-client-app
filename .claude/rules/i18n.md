# i18n & Localization Rules

- **Ngôn ngữ**: Tiếng Anh (`en.ts`) là ngôn ngữ chính và duy nhất. Chỉ thêm ngôn ngữ khác khi người dùng yêu cầu tường minh.
- **Không literal strings**: Mọi chuỗi hiển thị cho người dùng phải qua i18n (`tx` prop hoặc hàm `translate()`). Tuyệt đối không viết text trực tiếp trong JSX.
- **Tổ chức keys**: Nhóm keys theo feature hoặc component (`requests.form.categoryLabel`, `common.cancel`).
- **Data vs UI**: Dữ liệu lưu trong database và gửi lên API luôn dùng tiếng Anh chuẩn (`plastic`, `glass`, `mixed`). Chỉ UI phiên dịch sang nhãn hiển thị.
- **Thị trường Úc**: Tiền tệ AUD, định dạng ngày tháng `dd/MM/yyyy`, định dạng số điện thoại Úc (+61 / 04xx). Sử dụng `Intl` hoặc `date-fns`, không format thủ công bằng regex/string.
- **Server Dates**: Ngày tháng từ backend là ISO strings.
